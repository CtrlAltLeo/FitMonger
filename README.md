# FitMonger
> FitMonger is a web application with the goal of tracking outfits and articles of clothing, with an emphasis on sustainability and minimizing consumerism. 
> Log into FitMonger when at the thrift and check if those pants really go with that sweater.
> FitMonger helps you plan out hype fits and remember them.
> FitMonger also keeps track of when you've worn certain items. Been a while since you rocked that Nickelback T-Shirt? How about those fleece jeans? FitMonger reminds you to consider sustainability and sharing, and will let you know when it's time to think about donating clothing back to the thrift.

# Tech Stack
## Front End
- Site written in React, using Vite
- Runs on nginx docker continer
## Back End
### API - fitmongerapi
- Restful API using c#
### DB - fitmongerdb
- Postgres Docker Container
### BLOB Storage
- MinIO Blob Storages
